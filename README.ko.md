# claude-done

세션이 언제 끝났는지, 탭만 봐도 알 수 있게.

[English](README.md) · [日本語](README.ja.md) · [中文](README.zh.md) · [Español](README.es.md)

세션 하나만 돌릴 때는 화면을 계속 보고 있으니 필요가 없습니다. 진짜 쓸모는 여러 개를 동시에 돌릴 때 나옵니다. 터미널 탭마다 Claude를 띄워놓고 잠깐 자리를 비웠다가 돌아오면, 어느 게 방금 끝났고 어느 게 한참 전부터 멈춰 있었는지 화면만 봐서는 안 보입니다. claude-done은 턴이 끝날 때마다 그 시각을 한 줄로 남겨 둡니다. 그래서 탭만 흘깃 봐도 방금 끝난 건지 오래 멈춰 있는 건지 바로 보입니다. 한 줄 더 찍히는 것뿐이라, 평소엔 거슬리지도 않습니다.

## 어떻게 보이나

매 턴이 끝나면 아래 같은 한 줄이 찍힙니다.

```
완료: 2026년 06월 03일 03:39
```

| 로케일 | 출력 |
|--------|------|
| English | `Done: 03 Jun 2026, 03:39` |
| 한국어 | `완료: 2026년 06월 03일 03:39` |
| 日本語 | `完了: 2026年06月03日 03:39` |
| Español | `Hecho: 03 jun 2026, 03:39` |
| Deutsch | `Fertig: 03.06.2026, 03:39` |

맨 앞에 붙는 단어와 시각 형식은 로케일을 따라갑니다. Claude가 설정을 보고 맞는 형식을 하나 제안합니다. 마음에 안 들면 바꾸면 됩니다.

## 설치

Claude Code에 아래를 그대로 붙여넣으세요.

```
github.com/bidual/claude-done의 stop hook 설치해줘.
INSTALL.md 읽고 그대로 따라가면 돼.
```

Claude가 사용 언어와 시각 형식을 정해서 `~/.claude/settings.json`에 hook을 써넣고, 제대로 도는지 확인합니다. 그다음 턴부터 바로 동작합니다. [INSTALL.md](INSTALL.md)는 바이너리가 아니라 프롬프트라서 숨겨진 동작이 없습니다. 무슨 일을 하는지 그대로 읽어보면 됩니다.

## 동작 방식

Claude Code는 턴이 끝날 때마다 Stop hook을 실행합니다. claude-done의 hook은 이 명령 한 줄뿐입니다.

```
date +'{ "systemMessage": "완료: %Y년 %m월 %d일 %H:%M" }'
```

`date`가 현재 시각을 채워서 작은 JSON 하나를 출력하면, Claude Code가 그 `systemMessage` 필드를 읽어 화면에 보여줍니다. 백그라운드에서 도는 건 아무것도 없습니다. 형식은 표준 `date` 코드라 마음대로 바꿔도 됩니다(`man date` 참고). 초까지 보고 싶으면 `%S`를 붙이면 되고, 12시간제가 편하면 `%I:%M %p`로 바꾸면 됩니다.

## 바꾸거나 지우기

Claude Code 안에서 `/hooks`를 치면 hook을 보고, 고치고, 끌 수 있습니다. 아니면 `~/.claude/settings.json`의 `hooks.Stop`을 직접 손봐도 됩니다. 아예 없애려면 Stop 블록을 지우거나 Claude에게 지워달라고 하면 됩니다.
