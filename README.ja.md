# claude-done

Claude の応答が終わった時刻を、ターミナルにそっと残す Stop hook です。

[English](README.md) · [한국어](README.ko.md) · [中文](README.zh.md) · [Español](README.es.md)

## 何のためのものか

セッションが一つだけなら、ずっと画面を見ていればいいので、この hook の出番はありません。役に立つのは、複数のセッションをターミナルのタブに分けて同時に動かしている時です。ちょっと席を外して戻ってくると、どのタブがいつ終わったのか、transcript を見てもわかりません。

この hook は、Claude が応答を終えるたびに、その時刻を一行だけ表示します。タブをちらっと見れば、たった今終わったのか、それともだいぶ前に終わって、そのままになっているのかが、すぐ分かります。増えるのは一行だけで、ふだんは気になりません。

## 表示の例

| ロケール | 表示 |
|----------|------|
| English | `Done: 03 Jun 2026, 03:39` |
| 한국어 | `완료: 2026년 06월 03일 03:39` |
| 日本語 | `完了: 2026年06月03日 03:39` |
| Español | `Hecho: 03 jun 2026, 03:39` |
| Deutsch | `Fertig: 03.06.2026, 03:39` |

先頭の語も日時の書式も、ロケールに合わせて切り替わります。セットアップ時に Claude が候補を提案してくれるので、気に入らなければ書き換えてください。

## 入れ方

Claude Code に、次の二行をそのまま渡してください。

```
github.com/bidual/claude-done の stop hook を入れて。
INSTALL.md を読んで、その通りにやって。
```

あとは Claude が使用言語と日時の書式を判定し、hook を `~/.claude/settings.json` に書き込みます。動作を確認したうえで、次の作業へ進みます。[INSTALL.md](INSTALL.md) はバイナリではなくただのプロンプトです。裏で動くものは何もなく、中身はそのまま読めます。

## しくみ

やっていることは、このコマンド一本だけです。

```
date +'{ "systemMessage": "完了: %Y年%m月%d日 %H:%M" }'
```

ターンが終わるたびに、Claude Code がこれを Stop hook として実行します。`date` が現在時刻を差し込んだ小さな JSON を一つ出力します。Claude Code はその `systemMessage` フィールドを読み取って、画面に表示します。バックグラウンドで常駐し続けるプロセスはありません。

書式は `date` の標準的な書式コードで自由に変えられます。秒まで表示するなら `%S`、12 時間表記なら `%I:%M %p`。あとは `man date` の通りです。

## 変える・外す

Claude Code の中で `/hooks` を実行すると、登録した hook を一覧して、編集したり一時的に止めたりできます。手で直すなら、`~/.claude/settings.json` の `hooks.Stop` をいじってください。完全に外したい時は、その Stop ブロックを消すか、Claude に頼んでください。
